# Lock In v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the live Lock In v1 into v2: the Scoreboard redesign with 5 tabs, Day N, the any-work streak, the heatmap, rings, the funnel benchmark, LEGO, Work on this, interview prep, a recruiting calendar and a share card.

**Architecture:**
- **Database:** one new Supabase migration (`0003_v2.sql`) adds columns, six tables and a `day_activity` view.
- **Worker** (Python, GitHub Actions) learns:
  - in-progress idea completion
  - the any-work streak nudge
  - calendar items in the morning nudge
  - a `log-prep` CLI command
  - two launcher kinds (`work_on_idea`, `mock_interview`)
- **Web app** (React/Vite PWA):
  - keeps its data layer and tests
  - gets new tokens and fonts
  - gets a small component set (Ring, Heatmap, StatTile, FunnelTile, Segmented, IdeaCard)
  - is regrouped into 5 tabs with redirects
  - gains Prep, Calendar and Share screens
  Today's stats come from one hook (`useTodayStats`), shared by Today and the share card.

**Tech Stack:**
- Supabase Postgres with RLS
- Python 3.12 worker with pytest and `MemoryDB`
- React 19, react-router 7, TanStack Query 5, Vitest 3 + Testing Library, Playwright 1.55 + axe
- lucide-react icons
- `@fontsource/barlow-condensed` and `@fontsource/inter`

**Spec:** `docs/superpowers/specs/2026-10-14-lock-in-v2-design.md`. Read it before starting; it is the authority when this plan is unclear.

## Review Focus

1. **`day_one` in the future, or no activity at all.** Expect `DAY 0`, an empty heatmap, streak 0 and no crash. Tested in Task 7 (`activity.test.ts`) and Task 11 (Today with a future `day_one`).
2. **Activity between midnight and 3:59 AM ET**, including a DST change. It counts for the previous plan day in the web and the worker alike. Tested in Task 7 and Task 3.
3. **A commit made before Work on this was tapped must not complete the idea.** Tested in Task 2. A double tap must not queue two requests. Tested in Task 12 (the button is disabled while pending or queued).
4. **Old bookmarks and nudge links** (`/jobs`, `/leetcode`, `/settings`, …) still land on the right screen. Tested in Task 16 (`routes.test.tsx`) and Task 17 (e2e).
5. **Bad input to `lockin log-prep`** (minutes outside 1–600, unknown kind) exits 2 with a short error and writes nothing. Tested in Task 4.

```sql
-- Lock In v2: settings, optional repo, idea start time, launch kinds, prep, calendar, day_activity.
-- Idempotent: safe to re-run.

alter table public.settings
  add column if not exists day_one date not null default '2026-09-28',
  add column if not exists weekly_email_target int not null default 10;
alter table public.settings drop constraint if exists settings_weekly_email_target_check;
alter table public.settings add constraint settings_weekly_email_target_check check (weekly_email_target between 1 and 100);

alter table public.projects alter column repo drop not null;

alter table public.ideas add column if not exists started_at timestamptz;
alter table public.ideas drop constraint if exists ideas_status_check;
alter table public.ideas add constraint ideas_status_check check (status in ('todo','today','in_progress','done','dropped'));

alter table public.launch_requests drop constraint if exists launch_requests_kind_check;
alter table public.launch_requests add constraint launch_requests_kind_check check (kind in ('outreach','suggest_ideas','work_on_idea','mock_interview'));

create table if not exists public.stories (
  id uuid not null default gen_random_uuid(),
  owner uuid not null default auth.uid(),
  title text not null,
  tags text[] not null default '{}' check (tags <@ array['leadership','conflict','failure','impact','teamwork']::text[]),
  situation text not null default '',
  task text not null default '',
  action text not null default '',
  result text not null default '',
  last_practiced_on date,
  created_at timestamptz not null default now(),
  primary key (owner, id)
);

create table if not exists public.prep_sessions (
  id uuid not null default gen_random_uuid(),
  owner uuid not null default auth.uid(),
  kind text not null check (kind in ('oa','mock','study','story')),
  minutes int check (minutes between 1 and 600),
  note text,
  company text,
  story_id uuid,
  happened_on date not null,
  created_at timestamptz not null default now(),
  primary key (owner, id)
);

create table if not exists public.prep_items (
  id text primary key,
  track text not null check (track in ('system_design','cs')),
  title text not null,
  ord int not null
);

create table if not exists public.prep_progress (
  owner uuid not null default auth.uid(),
  item_id text not null,
  status text not null check (status in ('learning','solid')),
  updated_at timestamptz not null default now(),
  primary key (owner, item_id)
);

create table if not exists public.company_prep (
  id uuid not null default gen_random_uuid(),
  owner uuid not null default auth.uid(),
  company text not null,
  notes text not null default '',
  links text not null default '',
  interview_on date,
  created_at timestamptz not null default now(),
  primary key (owner, id),
  unique (owner, company)
);

create table if not exists public.events (
  id uuid not null default gen_random_uuid(),
  owner uuid not null default auth.uid(),
  title text not null,
  kind text not null check (kind in ('app_open','deadline','oa','interview','other')),
  on_date date not null,
  at_time time,
  company text,
  url text,
  created_at timestamptz not null default now(),
  primary key (owner, id)
);

alter table public.stories enable row level security;
drop policy if exists stories_owner on public.stories;
create policy stories_owner on public.stories for all to authenticated using (owner = auth.uid()) with check (owner = auth.uid());
alter table public.prep_sessions enable row level security;
drop policy if exists prep_sessions_owner on public.prep_sessions;
create policy prep_sessions_owner on public.prep_sessions for all to authenticated using (owner = auth.uid()) with check (owner = auth.uid());
alter table public.prep_progress enable row level security;
drop policy if exists prep_progress_owner on public.prep_progress;
create policy prep_progress_owner on public.prep_progress for all to authenticated using (owner = auth.uid()) with check (owner = auth.uid());
alter table public.company_prep enable row level security;
drop policy if exists company_prep_owner on public.company_prep;
create policy company_prep_owner on public.company_prep for all to authenticated using (owner = auth.uid()) with check (owner = auth.uid());
alter table public.events enable row level security;
drop policy if exists events_owner on public.events;
create policy events_owner on public.events for all to authenticated using (owner = auth.uid()) with check (owner = auth.uid());
alter table public.prep_items enable row level security;
drop policy if exists prep_items_read on public.prep_items;
create policy prep_items_read on public.prep_items for select to authenticated using (true);

create index if not exists prep_sessions_day on public.prep_sessions (owner, happened_on);
create index if not exists events_day on public.events (owner, on_date);

-- One row per owner per plan day (America/Detroit, day starts 04:00) from day_one through today.
create or replace view public.day_activity with (security_invoker = true) as
with s as (
  select owner, day_one,
         ((now() at time zone 'America/Detroit') - interval '4 hours')::date as today
  from public.settings
),
days as (
  select s.owner, d::date as day
  from s, generate_series(s.day_one, s.today, interval '1 day') as d
),
sv as (select owner, ((accepted_at at time zone 'America/Detroit') - interval '4 hours')::date as day, count(*) as n
       from public.lc_solves group by 1, 2),
av as (select owner, applied_on as day, count(*) as n from public.applications where applied_on is not null group by 1, 2),
ov as (select owner, sent_on as day, count(*) as n from public.outreach where sent_on is not null group by 1, 2),
cv as (select owner, ((committed_at at time zone 'America/Detroit') - interval '4 hours')::date as day, count(*) as n
       from public.commits group by 1, 2),
pv as (select owner, happened_on as day, count(*) as n from public.prep_sessions group by 1, 2),
j as (
  select d.owner, d.day,
         coalesce(sv.n, 0)::int as solves,
         coalesce(av.n, 0)::int as applications,
         coalesce(ov.n, 0)::int as outreach_sent,
         coalesce(cv.n, 0)::int as commits,
         coalesce(pv.n, 0)::int as prep_sessions
  from days d
  left join sv using (owner, day)
  left join av using (owner, day)
  left join ov using (owner, day)
  left join cv using (owner, day)
  left join pv using (owner, day)
)
select j.*,
       k.kinds,
       least(k.kinds, 4) as intensity,
       k.kinds > 0 as active
from j
cross join lateral (
  select (j.solves > 0)::int + (j.applications > 0)::int + (j.outreach_sent > 0)::int
       + (j.commits > 0)::int + (j.prep_sessions > 0)::int as kinds
) k;

grant usage on schema public to authenticated, service_role;
grant select, insert, update, delete on all tables in schema public to authenticated, service_role;
grant select on public.day_activity to authenticated, service_role;
```

```python
def complete_started_ideas(db) -> int:
    """Each in-progress idea is done by the first commit on its project made after it was started.
    Oldest-started ideas claim commits first; one commit completes at most one idea."""
    by_project: dict[str, list[dict]] = {}
    for idea in db.select("ideas", {"status": "in_progress"}):
        if idea.get("started_at"):
            by_project.setdefault(idea["project_id"], []).append(idea)
    done = 0
    for pid, ideas in by_project.items():
        commits = sorted(db.select("commits", {"project_id": pid}), key=lambda c: clock.parse_ts(c["committed_at"]))
        used: set[str] = set()
        for idea in sorted(ideas, key=lambda i: clock.parse_ts(i["started_at"])):
            t0 = clock.parse_ts(idea["started_at"])
            hit = next((c for c in commits if c["sha"] not in used and clock.parse_ts(c["committed_at"]) > t0), None)
            if hit is None:
                continue
            used.add(hit["sha"])
            db.update("ideas", {"id": idea["id"]}, {"status": "done", "done_at": hit["committed_at"]})
            done += 1
    return done
```

```python
from __future__ import annotations

from datetime import date, timedelta


def _d(v) -> date | None:
    if not v:
        return None
    return v if isinstance(v, date) else date.fromisoformat(str(v)[:10])


def agenda(db, day: date, limit: int = 3) -> list[str]:
    """Today's and tomorrow's calendar items as short phrases, earliest first."""
    tomorrow = day + timedelta(days=1)
    items: list[tuple[date, str, str]] = []
    for e in db.select("events"):
        d = _d(e.get("on_date"))
        if d in (day, tomorrow):
            items.append((d, str(e.get("at_time") or "99"), e["title"]))
    for p in db.select("company_prep"):
        d = _d(p.get("interview_on"))
        if d in (day, tomorrow):
            items.append((d, "99", f"{p['company']} interview"))
    for o in db.select("outreach", {"status": "sent"}):
        d = _d(o.get("follow_up_on"))
        if d in (day, tomorrow):
            items.append((d, "99~", f"Follow up: {o.get('company') or 'outreach'}"))
    items.sort(key=lambda t: (t[0], t[1], t[2]))
    return [f"{text} {'today' if d == day else 'tomorrow'}" for d, _, text in items[:limit]]
```

  Notes on the sort key:
  - Untimed items sort after timed ones on the same day ("99").
  - Follow-ups sort last ("99~").
  - Ties sort by text: "Career fair" (09:00) sorts before "Stripe OA" (15:00), which is why the test expects that order.

```python
def slugify(text: str) -> str:
    s = re.sub(r"[^a-z0-9]+", "-", text.lower()[:40]).strip("-")

def readme_head(cwd: Path, lines: int = README_LINES) -> str:
    p = cwd / "README.md"
    if not p.is_file():
        return "No README."
    return "\n".join(p.read_text(encoding="utf-8", errors="replace").splitlines()[:lines])

def format_stories(stories: list[dict]) -> str:
    if not stories:

    out = []
    for s in stories:
        tags = f" ({', '.join(s.get('tags') or [])})" if s.get("tags") else ""
        out.append("\n".join([
            f"### {s['title']}{tags}",
            f"- Situation: {s.get('situation') or '-'}",
            f"- Task: {s.get('task') or '-'}",
            f"- Action: {s.get('action') or '-'}",
            f"- Result: {s.get('result') or '-'}",
        ]))
    return "\n\n".join(out)
```

```ts
import type { Application, Commit, Outreach, PrepSession, Solve } from '../data/types';
import { streak } from './streaks';
import { TZ, addDays, daysBetween, planDay, weekStart } from './time';

export interface ActivityInput {
  solves: Pick<Solve, 'accepted_at'>[];
  applications: Pick<Application, 'applied_on'>[];
  outreach: Pick<Outreach, 'sent_on'>[];
  commits: Pick<Commit, 'committed_at'>[];
  prep: Pick<PrepSession, 'happened_on'>[];
}
export interface DayActivity {
  day: string; solves: number; applications: number; outreach: number; commits: number; prep: number;
  kinds: number; intensity: 0 | 1 | 2 | 3 | 4; active: boolean;
}

function tally(days: (string | null)[]): Map<string, number> {
  const m = new Map<string, number>();
  for (const d of days) if (d) m.set(d, (m.get(d) ?? 0) + 1);
  return m;
}

export function dayN(dayOne: string, today: string): number {
  return dayOne > today ? 0 : daysBetween(dayOne, today) + 1;
}

/** One entry per plan day from dayOne through today. Mirrors the SQL view public.day_activity. */
export function dayActivity(input: ActivityInput, dayOne: string, today: string): DayActivity[] {
  const n = dayN(dayOne, today);
  if (n === 0) return [];
  const s = tally(input.solves.map((x) => planDay(new Date(x.accepted_at))));
  const a = tally(input.applications.map((x) => x.applied_on));
  const o = tally(input.outreach.map((x) => x.sent_on));
  const c = tally(input.commits.map((x) => planDay(new Date(x.committed_at))));
  const p = tally(input.prep.map((x) => x.happened_on));
  return Array.from({ length: n }, (_, i) => {
    const day = addDays(dayOne, i);
    const row = { day, solves: s.get(day) ?? 0, applications: a.get(day) ?? 0, outreach: o.get(day) ?? 0, commits: c.get(day) ?? 0, prep: p.get(day) ?? 0 };
    const kinds = [row.solves, row.applications, row.outreach, row.commits, row.prep].filter((v) => v > 0).length;
    return { ...row, kinds, intensity: Math.min(kinds, 4) as DayActivity['intensity'], active: kinds > 0 };
  });
}

export function activeStreak(days: DayActivity[], today: string): number {
  return streak(new Set(days.filter((d) => d.active).map((d) => d.day)), today);
}

/** Columns of 7 (Mon..Sun), oldest first; null where a cell falls outside the days given. */
export function heatmapWeeks(days: DayActivity[]): (DayActivity | null)[][] {
  if (days.length === 0) return [];
  const byDay = new Map(days.map((d) => [d.day, d]));
  const start = weekStart(days[0].day);
  const weeks = Math.floor(daysBetween(start, weekStart(days[days.length - 1].day)) / 7) + 1;
  return Array.from({ length: weeks }, (_, w) => Array.from({ length: 7 }, (_, i) => byDay.get(addDays(start, w * 7 + i)) ?? null));
}

const lineFmt = new Intl.DateTimeFormat('en-US', { timeZone: TZ, weekday: 'short', month: 'numeric', day: 'numeric' });
/** "WED 10/14" for the plan day of `now`. */
export function dayLine(now: Date): string {
  const p: Record<string, string> = {};
  const shifted = new Date(now.getTime() - 4 * 3_600_000);
  for (const part of lineFmt.formatToParts(shifted)) p[part.type] = part.value;
  return `${p.weekday.toUpperCase()} ${p.month}/${p.day}`;
}
```

```ts
import type { CalEvent, CompanyPrep, EventKind, Outreach } from '../data/types';
import { addDays, daysBetween, shortDate, weekStart } from './time';

export interface CalItem {
  key: string; title: string; kind: EventKind; on_date: string; at_time: string | null;
  company: string | null; url: string | null; eventId: string | null;
}

export const KIND_LABEL: Record<EventKind, string> = {
  app_open: 'Apps open', deadline: 'Deadline', oa: 'OA', interview: 'Interview', other: 'Other',
};
const PRIORITY: EventKind[] = ['interview', 'oa', 'deadline', 'app_open', 'other'];

export function calendarItems(events: CalEvent[], prep: CompanyPrep[], outreach: Outreach[]): CalItem[] {
  const items: CalItem[] = [
    ...events.map((e) => ({ key: `e:${e.id}`, title: e.title, kind: e.kind, on_date: e.on_date, at_time: e.at_time, company: e.company, url: e.url, eventId: e.id })),
    ...prep.filter((p) => p.interview_on).map((p) => ({
      key: `p:${p.id}`, title: `${p.company} interview`, kind: 'interview' as const, on_date: p.interview_on!, at_time: null, company: p.company, url: null, eventId: null,
    })),
    ...outreach.filter((o) => o.status === 'sent' && o.follow_up_on).map((o) => ({
      key: `o:${o.id}`, title: `Follow up: ${o.company ?? 'outreach'}`, kind: 'other' as const, on_date: o.follow_up_on!, at_time: null, company: o.company, url: null, eventId: null,
    })),
  ];
  return items.sort((a, b) => a.on_date.localeCompare(b.on_date) || (a.at_time ?? '99').localeCompare(b.at_time ?? '99') || a.title.localeCompare(b.title));
}

export const upcoming = (items: CalItem[], today: string) => items.filter((i) => i.on_date >= today);

export function countdown(day: string, today: string): string {
  const n = daysBetween(today, day);
  if (n === 0) return 'today';
  if (n === 1) return 'tomorrow';
  if (n > 1) return `in ${n} days`;
  return n === -1 ? 'yesterday' : `${-n} days ago`;
}

export function groupByWeek(items: CalItem[], today: string): { label: string; items: CalItem[] }[] {
  const thisWeek = weekStart(today);
  const groups = new Map<string, CalItem[]>();
  for (const i of items) {
    const w = weekStart(i.on_date);
    groups.set(w, [...(groups.get(w) ?? []), i]);
  }
  return [...groups.entries()].sort(([a], [b]) => a.localeCompare(b)).map(([w, list]) => ({
    label: w === thisWeek ? 'This week' : w === addDays(thisWeek, 7) ? 'Next week' : `Week of ${shortDate(w)}`,
    items: list,
  }));
}

/** "YYYY-MM" ± n months. */
export function addMonths(month: string, n: number): string {
  const y = Number(month.slice(0, 4));
  const m = Number(month.slice(5, 7)) - 1 + n;
  const yy = y + Math.floor(m / 12);
  const mm = ((m % 12) + 12) % 12;
  return `${yy}-${String(mm + 1).padStart(2, '0')}`;
}

/** Weeks (Mon..Sun) covering the month; days outside the month are null. */
export function monthGrid(month: string): (string | null)[][] {
  const first = `${month}-01`;
  const next = `${addMonths(month, 1)}-01`;
  const start = weekStart(first);
  const weeks: (string | null)[][] = [];
  for (let d = start; d < next; d = addDays(d, 7)) {
    weeks.push(Array.from({ length: 7 }, (_, i) => {
      const day = addDays(d, i);
      return day >= first && day < next ? day : null;
    }));
  }
  return weeks;
}

export function dotKind(items: CalItem[]): EventKind | null {
  for (const k of PRIORITY) if (items.some((i) => i.kind === k)) return k;
  return null;
}

const when = (n: number) => (n === 0 ? 'today' : n === 1 ? 'tomorrow' : `in ${n} days`);

export function weekFocus(items: CalItem[], today: string, appTarget: number): { text: string; to: string | null } {
  const soon = items.filter((i) => { const n = daysBetween(today, i.on_date); return n >= 0 && n <= 7; });
  const first = (k: EventKind) => soon.find((i) => i.kind === k);
  const iv = first('interview');
  if (iv) return { text: `Interview ${when(daysBetween(today, iv.on_date))}: mock + company notes`, to: '/grind/prep' };
  const oa = first('oa');
  if (oa) return { text: `OA ${when(daysBetween(today, oa.on_date))}: daily OA practice`, to: '/grind/prep' };
  const dl = first('deadline');
  if (dl) return { text: `Deadline ${when(daysBetween(today, dl.on_date))}: ${dl.title}`, to: null };
  return { text: `Volume week: hit ${appTarget} applications`, to: '/hunt/jobs' };
}
```

```ts
import { daysBetween, weekStart } from './time';

export const PREP_KIND_LABEL: Record<PrepKind, string> = { oa: 'OA', mock: 'Mock', study: 'Study', story: 'Story' };
const PREP_STAGES: Stage[] = ['oa', 'interview', 'offer'];

export interface PrepCompany { company: string; prep: CompanyPrep | null; stage: Stage | null; days: number | null }

export function prepCompanies(apps: Application[], prep: CompanyPrep[], today: string): PrepCompany[] {
  const out = new Map<string, PrepCompany>();
  for (const p of prep) out.set(norm(p.company), { company: p.company, prep: p, stage: null, days: p.interview_on ? daysBetween(today, p.interview_on) : null });
  for (const a of apps) {
```

```ts
import { useEffect, useState } from 'react';

export function prefersReducedMotion(): boolean {
  return typeof window.matchMedia !== 'function' || window.matchMedia('(prefers-reduced-motion: reduce)').matches;
}

/** False on the first paint, true on the next frame, so CSS transitions run from their start state. */
export function useMounted(): boolean {
  const [on, setOn] = useState(false);
  useEffect(() => {
    if (prefersReducedMotion() || typeof requestAnimationFrame !== 'function') { setOn(true); return; }
    const id = requestAnimationFrame(() => setOn(true));
    return () => cancelAnimationFrame(id);
  }, []);
  return on;
}

/** Counts from 0 to target over `ms`; returns target immediately under reduced motion or without matchMedia. */
export function useCountUp(target: number, ms = 600): number {
  const [v, setV] = useState(() => (prefersReducedMotion() ? target : 0));
  useEffect(() => {
    if (prefersReducedMotion() || typeof requestAnimationFrame !== 'function') { setV(target); return; }
    const t0 = performance.now();
    let id = 0;
    const tick = (t: number) => {
      const k = Math.min(1, (t - t0) / ms);
      setV(Math.round(target * (1 - (1 - k) ** 3)));
      if (k < 1) id = requestAnimationFrame(tick);
    };
    id = requestAnimationFrame(tick);
    return () => cancelAnimationFrame(id);
  }, [target, ms]);
  return v;
}
```

```ts
import { useMemo } from 'react';
import { activeStreak, dayActivity, dayLine, dayN, heatmapWeeks, type DayActivity } from '../lib/activity';
import { appliedThisWeek, funnel, type FunnelRow } from '../lib/funnel';
import { sentThisWeek } from '../lib/outreach';
import { planDay } from '../lib/time';
import { buildTodayItems } from '../lib/today';
import {
  useApplications, useCommits, useDailySet, useNow, useOutreach, usePrepSessions, useProblemMap, useSettings, useSolves,
} from './hooks';

export interface TodayStats {
  day: string; dateLine: string; n: number; streak: number; days: DayActivity[]; weeks: (DayActivity | null)[][];
  lcDone: number; lcTotal: number; appsWeek: number; appTarget: number; emailsWeek: number; emailTarget: number; funnel: FunnelRow[];
}

export function useTodayStats(): { state: 'loading' | 'error' | 'ready'; retry: () => void; stats: TodayStats | null } {
  const now = useNow();
  const day = planDay(now);
  const settings = useSettings();
  const set = useDailySet(day);
  const solves = useSolves();
  const problems = useProblemMap();
  const commits = useCommits();
  const apps = useApplications();
  const outreach = useOutreach();
  const prep = usePrepSessions();
  const dateLine = dayLine(now);
  const stats = useMemo((): TodayStats | null => {
    const s = settings.data;
    if (!s) return null;
    const days = dayActivity({
      solves: solves.data ?? [], applications: apps.data ?? [], outreach: outreach.data ?? [],
      commits: commits.data ?? [], prep: prep.data ?? [],
    }, s.day_one, day);
    const items = set.data ? buildTodayItems(set.data, solves.data ?? [], problems, day) : [];
    return {
      day, dateLine, n: dayN(s.day_one, day), streak: activeStreak(days, day), days, weeks: heatmapWeeks(days),
      lcDone: items.filter((i) => i.done).length, lcTotal: items.length,
      appsWeek: appliedThisWeek(apps.data ?? [], day), appTarget: s.weekly_app_target,
      emailsWeek: sentThisWeek(outreach.data ?? [], day), emailTarget: s.weekly_email_target,
      funnel: funnel(apps.data ?? []),
    };
  }, [settings.data, solves.data, apps.data, outreach.data, commits.data, prep.data, set.data, problems, day, dateLine]);
  return {
    state: settings.isPending ? 'loading' : settings.isError ? 'error' : 'ready',
    retry: () => void settings.refetch(),
    stats,
  };
}
```

```tsx
const EMPTY_STORY: StoryInput = { title: '', tags: [], situation: '', task: '', action: '', result: '' };

function StoryForm({ initial, submitLabel, busy, onSave, onCancel }: {
  initial: StoryInput; submitLabel: string; busy: boolean; onSave: (s: StoryInput) => void; onCancel?: () => void;
}) {
  const [f, setF] = useState<StoryInput>({ title: initial.title, tags: initial.tags, situation: initial.situation, task: initial.task, action: initial.action, result: initial.result });
  const [err, setErr] = useState<string | null>(null);
  const submit = (e: FormEvent) => {
    e.preventDefault();
    if (!f.title.trim()) { setErr('Title is required.'); return; }
    setErr(null);
    onSave({ ...f, title: f.title.trim() });
  };
  const area = (k: 'situation' | 'task' | 'action' | 'result', label: string) => (
    <label className="field"><span>{label}</span>
      <textarea rows={2} maxLength={1500} value={f[k]} onChange={(e) => setF({ ...f, [k]: e.target.value })} /></label>
  );
  return (
    <form className="stack" onSubmit={submit}>
      <label className="field"><span>Title</span>
        <input maxLength={120} value={f.title} onChange={(e) => setF({ ...f, title: e.target.value })} /></label>
      <div className="chips" role="group" aria-label="Tags">
        {STORY_TAGS.map((t) => (
          <Chip key={t} pressed={f.tags.includes(t)}
            onToggle={() => setF({ ...f, tags: f.tags.includes(t) ? f.tags.filter((x) => x !== t) : [...f.tags, t] })}>{t}</Chip>
        ))}
      </div>
      {area('situation', 'Situation')}{area('task', 'Task')}{area('action', 'Action')}{area('result', 'Result')}
      {err && <p role="alert" className="error small">{err}</p>}
      <div className="row-actions">
        <Button type="submit" variant="primary" disabled={busy}>{submitLabel}</Button>
        {onCancel && <Button variant="quiet" onClick={onCancel}>Cancel</Button>}
      </div>
    </form>
  );
}
```

```ts
function box(ctx: CanvasRenderingContext2D, x: number, y: number, w: number, h: number, r: number) {

  ctx.arcTo(x, y + h, x, y, r);
```

```tsx
import { Share2 } from 'lucide-react';
import { useEffect, useMemo, useRef, useState } from 'react';
import { useTodayStats } from '../data/useTodayStats';
import { CARD_H, CARD_W, caption, drawCard, toCardData } from '../lib/shareCard';
import { Button, Card, CopyButton, LoadError, Skeleton } from '../ui/primitives';

const FAIL = "Couldn't make the image.";

async function loadFonts() {
  try {
    await Promise.all([
      document.fonts?.load('italic 800 100px "Barlow Condensed"'),
      document.fonts?.load('800 100px "Barlow Condensed"'),
      document.fonts?.load('500 40px "Barlow Condensed"'),
    ]);
  } catch { /* draw with fallbacks */ }
}

export default function Share() {
  const { state, retry, stats } = useTodayStats();
  const [showFunnel, setShowFunnel] = useState(true);
  const [err, setErr] = useState<string | null>(null);
  const canvas = useRef<HTMLCanvasElement>(null);
  const data = useMemo(() => (stats ? toCardData(stats, showFunnel) : null), [stats, showFunnel]);
  const key = data ? JSON.stringify(data) : '';

  useEffect(() => {
    if (!data || !canvas.current) return;
    let alive = true;
    const ctx = canvas.current.getContext('2d');
    if (!ctx) { setErr(FAIL); return; }
    void loadFonts().then(() => { if (alive) { drawCard(ctx, data); setErr(null); } });
    return () => { alive = false; };
    // eslint-disable-next-line react-hooks/exhaustive-deps -- `key` captures `data` by value
  }, [key]);

  if (state === 'loading') return <Skeleton label="Loading card" />;
  if (state === 'error' || !stats || !data) return <LoadError what="today" onRetry={retry} />;

  const share = async () => {
    const c = canvas.current;
    if (!c) return;
    const blob = await new Promise<Blob | null>((r) => c.toBlob(r, 'image/png'));
    if (!blob) { setErr(FAIL); return; }
    const name = `lock-in-day-${data.day}.png`;
    const file = new File([blob], name, { type: 'image/png' });
    if (navigator.canShare?.({ files: [file] })) {
      try { await navigator.share({ files: [file], text: caption(data) }); } catch { /* cancelled */ }
      return;
    }
    const url = URL.createObjectURL(blob);
    const a = document.createElement('a');
    a.href = url;
    a.download = name;
    a.click();
    window.setTimeout(() => URL.revokeObjectURL(url), 1000);
  };

  return (
    <div className="screen">
      <header className="screen-head"><h1>Share</h1></header>
      <Card data-primary aria-labelledby="card-h">
        <h2 id="card-h" className="sr-only">Today's card</h2>
        <canvas ref={canvas} width={CARD_W} height={CARD_H} className="share-canvas" role="img"
          aria-label={`Day ${data.day} card: ${data.streak} day streak, ${data.lcDone} of ${data.lcTotal} LeetCode, ${data.appsWeek} apps this week`} />
        {err && <p role="alert" className="error small">{err}</p>}
        <label className="check-row">
          <input type="checkbox" checked={showFunnel} onChange={(e) => setShowFunnel(e.target.checked)} />
          <span>Show funnel</span>
        </label>
        <div className="row-actions">
          <Button variant="primary" onClick={() => void share()}><Share2 size={18} aria-hidden />Share image</Button>
          <CopyButton text={caption(data)} label="Copy caption" variant="ghost" />
        </div>
        <p className="muted small share-caption">{caption(data)}</p>
      </Card>
    </div>
  );
}
```
